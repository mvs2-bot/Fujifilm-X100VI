# Fujifilm X100VI · Kamerakarte

Interaktive Karte aller Bedienelemente der Fujifilm X100VI (oben, vorne, hinten, Seite, unten) mit Funktion, Werkseinstellung, Anpassung und Praxistipp. Statische Seite ohne Login, ohne Tracking.

**Live:** https://mvs2-bot.github.io/Fujifilm-X100VI/

- `index.html` – die komplette Seite (HTML, CSS, JS in einer Datei)
- `img/` – eigene Fotos der Kamera, Metadaten (EXIF/GPS) entfernt
- Inhalte geprüft gegen das [offizielle Fujifilm-Handbuch](https://fujifilm-dsc.com/en/manual/x100vi/); keine Fujifilm-Bilder eingebunden.
